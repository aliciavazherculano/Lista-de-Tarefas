📝 Lista de Tarefas em Java

Aplicação de console para gerenciar tarefas, feita em Java puro. As tarefas ficam salvas em arquivo, então continuam lá quando você abre o programa de novo.

✨ Funcionalidades
Adicionar tarefa
Listar tarefas
Marcar tarefa como concluída
Remover tarefa
Salvar e carregar automaticamente de um arquivo (tarefas.txt)

🛠️ Tecnologias
Java 11 ou superior
IntelliJ IDEA

🚀 Como rodar
Clone o repositório:
bash
   git clone https://github.com/aliciavazherculano/lista-de-tarefas-java.git
Abra a pasta no IntelliJ IDEA
Rode a classe Principal

📁 Estrutura
src/

├── Tarefa.java      # modelo de uma tarefa

└── Principal.java   # menu e lógica do programa

📚 O que pratiquei neste projeto
Classes, atributos privados, construtores e getters
Listas (ArrayList) e laços de repetição
Scanner, switch e métodos
Leitura e escrita de arquivos com Files
Tratamento de erros com try/catch
